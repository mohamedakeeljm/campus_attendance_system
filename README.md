# Staff Attendance System (Next.js App Router)

A high-performance Next.js web application built for processing biometric attendance Excel exports and generating formatted monthly attendance workbooks for HR teams.

Designed and optimized for seamless serverless deployment on **Vercel** with 100% in-memory buffer processing.

---

## 🚀 Features

- **Biometric Log Parsing**: Reads `.xls` and `.xlsx` files generated by fingerprint and biometric attendance machines (specifically extracting data from the `Logs` sheet).
- **Automated Name Mapping**: Automatically maps biometric short names (e.g. `misfa`, `siyam`, `shakeeb`) to official employee full names (e.g. `A.F.Misfa`, `M. Mohamed Siyam`, `MIM. Shakeeb`).
- **Dynamic Date & Day Calculation**: Detects attendance cycles (e.g., 26th to 25th) and automatically derives calendar days of the week (`Wed`, `Thur`, `Fri`, `Sat`, `Sun`, `Mon`, `Tues`...).
- **Configurable Attendance Rules**: Extensible configuration in `lib/attendanceConfig.ts` with placeholder logic for Half Day (`HD`), Early Departure (`ED`), and Weekend (`W`) handling.
- **Serverless & In-Memory**: Zero file system (`fs`) writes. Processes workbooks entirely in memory using Buffers and streams binary `.xlsx` downloads directly to clients.
- **Modern Responsive UI**: Drag-and-drop file upload zone, instant attendance preview table, status badges, and download triggers.
- **Robust Error Handling**: Friendly error messages when the required `Logs` sheet is missing or when malformed files are provided.

## 📋 Input & Output Specifications

### Input Format (`001_2026_8_MON.XLS`)
- Target sheet: `Logs`
- Date headers: e.g. `26, 27, 28 ... 24, 25`
- Employee two-row blocks:
  - Row A: `No : [ID] ... Name : [Short Name] ... Dept : [Department]`
  - Row B: Multi-line timestamp string (e.g. `"08:43\n17:04\n"`) or empty/`NaN`

### Output Format (`Staff Attandance.xlsx`)
- **Row 1**: Header title (e.g., `EMPLOYEE ATTENDANCE - SEPTEMBER 2026`)
- **Row 2**: Days of the week (`Wed`, `Thur`, `Fri`, `Sat`, `Sun`, `Mon`, `Tues`...)
- **Row 3**: Dates (`26, 27, 28... 24, 25`) with Column A set to `EMPLOYEE NAME`
- **Row 4+**: Full employee names in Column A, attendance statuses in Columns B onwards:
  - `P` = Present
  - `H` = Holiday
  - `HD` = Half Day
  - `ED` = Early Departure
  - `C` = Casual Leave
  - `W` = Weekend

Edit [`lib/attendanceConfig.ts`](file:///c:/Users/SOOQ%20ELASER/Desktop/Staff%20Attendance/Staff%20Attendance%20System/lib/attendanceConfig.ts):

### 1. Adding Employee Name Mappings

```typescript
export const nameMapping: Record<string, string> = {
  "misfa": "A.F.Misfa",
  "siyam": "M. Mohamed Siyam",
  "new_employee": "A.B. Full Name",
};
```

### 2. Changing Weekend Days
```typescript
// Example: Mark both Saturdays and Sundays as Weekend ("W")
export const standardWeekendDays = ["Sat", "Sun"];
```

### 3. Half Day (HD) & Early Departure (ED) Logic
Uncomment or customize rules inside `calculateDailyStatus`:
```typescript
export function calculateDailyStatus(punchIn, punchOut, date) {
  if (punchIn || punchOut) {
    const outTime = punchOut || punchIn;
    // Example: Left before 13:30
    if (outTime < "13:30") return "HD";
    // Example: Left before 16:30
    if (outTime < "16:30") return "ED";
    return "P";
  }

  if (date?.isWeekend) return "W";
  return "";
}
```

1. Push this repository to GitHub or GitLab.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Select your repository.
4. Click **Deploy**. Vercel will automatically detect Next.js App Router and deploy without extra configuration.
